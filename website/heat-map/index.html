Method

z = clamp((P - P10) / (P90 - P10), 0, 1), alpha = 1 + 0.5*z.

base = Ncar*EFcar + Ntruck*EFtruck + Nbus*EFbus + Nmoto*EFmoto.

E_total = base * alpha. Intensity = E_total / max(N_total, 1).

P10/P90 are daily percentiles of peak vehicles per frame across cameras.
